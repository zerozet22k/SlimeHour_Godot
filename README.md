# Slime Hour

[Download the Windows game](https://github.com/zerozet22k/SlimeHour_Godot/releases/latest): get `SlimeHour-Windows.zip`, extract it, and run `SlimeHour.exe`.

For automatic updates on Windows, download the source repository and run `Start_Slime_Hour.bat`. It checks GitHub Releases, verifies the ZIP checksum, and launches the newest build. To open the Godot project itself, clone with Git LFS and run `PLAY_WINDOWS.bat`.

Android is planned for later. The Android export preset remains in the source, but no APK is included in the repository.
