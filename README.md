# Slime Hour

[Download the Windows game](https://github.com/zerozet22k/SlimeHour_Godot/releases/latest): get `SlimeHour-Windows.zip`, extract it, and run `SlimeHour.exe`. The game checks for a new release each time it starts. When one is available, choose **UPDATE** on the main menu to install and launch it.

The release ZIP includes the updater and checksum configuration. To open the Godot project itself, clone with Git LFS and run `PLAY_WINDOWS.bat`.

Android is planned for later. The Android export preset remains in the source, but no APK is included in the repository.
